## 핵심 개념: Agent = 모델 + Context + 도구

이 책의 핵심 프레임워크는 **Agent = 모델 + Context + 도구**이며, 세 구성 요소가 협력해 Agent의 지능적 행동을 실현합니다:

| 구성 요소 | 비유 | 역할 |
| :--: | :--: | --- |
| 🧠 **모델(Model)** | 뇌 | 이해, 추론, 의사결정 능력 제공 |
| 💾 **Context** | 운영체제 | 시스템 지시, 대화 이력, 추론 과정, 도구 상호작용 기록 등 |
| 🤲 **도구(Tools)** | 두 손 | 환경 인지, 행동 실행, 외부 세계와의 상호작용 |

## 학습 경로

이 책 전체는 「모델 / Context / 도구」라는 세 축을 중심으로 층층이 전개됩니다. 각 편에는 핵심 통찰이 하나씩 붙어 있습니다:

| 편 | 장 | 다루는 내용 | 핵심 통찰 |
| --- | :--: | --- | --- |
| **기초편** | 제1장 | RL에서의 Agent 정의, 전통적 RL vs LLM+RL 샘플 효율성, "모델이 곧 Agent"라는 새로운 패러다임 | 사전 지식의 중요성은 알고리즘과 환경을 능가한다 |
| **Context편** | 제2~3장 | 시스템 프롬프트, KV Cache, context 압축, 프롬프트 엔지니어링; 사용자 메모리, dense/sparse/hybrid 검색, Agentic RAG | 완전한 context = 시스템 지시 + 대화 이력 + 추론 과정 + 도구 기록 + 사용자 메모리 + 외부 지식 |
| **도구편** | 제4~5장 | 인지/실행/협업 세 유형의 MCP 도구, 이벤트 기반 비동기 아키텍처; 프로덕션급 Coding Agent 전체 구현 | 도구 설계는 범용화해야 한다(코드 인터프리터가 계산기보다 낫다), 코드는 새 도구를 만들어내는 메타 능력이다 |
| **모델편** | 제6~7장 | Terminal-Bench/SWE-bench/GAIA/OSWorld/Tau2-Bench 평가 벤치마크; SFT, RL, RLHF, 샘플 효율성 | 독립적인 검증 신호가 「모델에게 다시 생각해 보라고 하는 것」보다 더 신뢰할 수 있다; RL은 도구 호출을 네이티브 능력으로 내재화한다 |
| **자기진화편** | 제8장 | 경험 학습, 워크플로를 도구로 외재화, 프롬프트와 관찰을 파라미터로 증류 | 경험으로부터 학습하는 것은 Agent가 「똑똑함」에서 「숙련됨」으로 나아가는 핵심이다 |
| **확장과 협업편** | 제9~10장 | 음성/GUI/물리 세계에서의 멀티모달 상호작용; 멀티 Agent 협업 | 멀티 Agent의 모든 설계 결정은 단일 Agent의 세 요소에서 대응점을 찾을 수 있다 |

## 난이도 분류

| 레벨 | 장 | 적합한 독자 |
| --- | :--: | --- |
| 🟢 입문 | 제1~2장 | 초보자, 기본 개념 이해 |
| 🔵 중급 | 제3~4장 | 어느 정도 프로그래밍 기초가 있고, 시스템 통합을 다룸 |
| 🟣 고급 | 제5~6장 | 프로그래밍 능력이 뛰어나고, 복잡한 시스템 설계를 다룸 |
| 🔴 전문가 | 제7~8장 | 딥러닝과 학습/자기 진화 경험이 있음 |
| 🟠 응용 | 제9~10장 | 앞서 배운 내용을 종합적으로 활용해 실제 애플리케이션을 구축 |
